WHAT WOULD YOU FIX FIRST?

GOOD CHOICE.

Typography would definitely help. Changing font sizes, weights, and styles would make the information easier to understand. It's important to note the difference between readability and legibility.

GOOD CHOICE.

Color can create contrast and help important information stand out. The current colors definitely need some help. Also, it's ugly.

BEST CHOICE!

Hierarchy gives the viewer an order to follow. Without hierarchy, everything competes for attention. Creating a clear heading, subheading, and body text would make this design much easier to understand.

ABOUT THE EXPERIMENT

HOW IT WORKS.

This experiment uses HTML radio buttons and CSS to create a simple interactive experience without JavaScript. I'm too lazy to even try to integrate Javascript. My brain is fried. Selecting an answer changes what is displayed on the page. This experiment was created with the assistance of Gemini's HTML and CSS generative AI. What I loved about working with radio buttons is how often I actually see them on webpages. It's a simple drop down menu. I didn't realize it could be used to turn into some sort of game.
